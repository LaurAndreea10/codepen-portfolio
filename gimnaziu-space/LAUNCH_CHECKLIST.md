# Checklist de lansare

## Tehnic

- [ ] Live URL funcționează pe HTTPS.
- [ ] Rutele acasă, formule, quiz, coach, arhivă, instrumente și feedback se încarcă.
- [ ] Service worker și manifest funcționează.
- [ ] Dark mode, RO/EN, contrast, text mărit și reduced motion sunt verificate.
- [ ] Export/import și feedback local funcționează.
- [ ] Nu există erori JavaScript în traseul de testare.

## Conținut

- [ ] Formule și memoratoare verificate.
- [ ] Simulări marcate ca orientative.
- [ ] Arhiva oficială și baremele sunt accesibile.
- [ ] Mențiunea „Nu este material didactic” este vizibilă.

## Prezentare

- [ ] README actualizat.
- [ ] Capturi reale făcute din versiunea live.
- [ ] Postare Facebook pregătită.
- [ ] Postare LinkedIn pregătită.
- [ ] Publicarea socială se face manual, după verificarea finală și confirmarea proprietarului conturilor.

## După lansare

- [ ] Se colectează feedbackul din primele 7 zile.
- [ ] Se grupează problemele în: blocant, important, cosmetic.
- [ ] Se publică o versiune nouă după prioritizare.
- [ ] Android se ia în calcul după validarea utilizării web, nu înainte.
