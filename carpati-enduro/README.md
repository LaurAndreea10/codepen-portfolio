# Carpați Enduro

Joc moto 3D în browser (enduro, motocross, trial). Fișier unic + PWA.

## Publicare pe GitHub Pages
1. Copiază folderul `carpati-enduro/` în repo-ul `codepen-portfolio`.
2. Fă commit și push. Jocul va fi la `https://laurandreea10.github.io/codepen-portfolio/carpati-enduro/`.
3. La prima vizită se salvează în cache; după aceea merge și offline.
4. Pe Android/desktop apare butonul „Instalează aplicația” în meniu. Pe iPhone: Partajează → Adaugă pe ecranul principal.

## Actualizări
Când modifici `index.html`, schimbă `CACHE` din `sw.js` (de ex. `carpati-enduro-v2`) ca jucătorii să primească versiunea nouă.
