Carpați Enduro

Moto × enduro × trial · Expedition 2.1

Problema

Un joc moto în browser trebuie să combine controlul accesibil cu obstacole suficient de variate pentru a recompensa învățarea. Pe mobil, comenzile mici și nevoia de apăsare continuă pot împiedica accesul.

Soluția

O singură experiență pentru curse AI, trial, expediții în etape și trasee construite de jucător. Comenzile tactile pot fi mărite, grupate, repoziționate sau comutate. Asistența, viteza jocului și sensibilitatea sunt reglabile.

Implementare

HTML, CSS și JavaScript, fizică pe puncte și constrângeri, teren generat determinist, adversari AI și randare Three.js cu alternativă Canvas 2D. Presiunea pneurilor, suspensia și distribuția frânei modifică simularea. Clasamentele locale sunt separate după regulile cursei.

UI și UX

Meniul existent este păstrat. Expedition Studio reunește modurile noi, editorul, misiunile, reglajele, jocul local cu prietenii, reluările, analiza și backupurile. RO/EN, dark/light, contrast ridicat și mișcare redusă sunt disponibile.

Provocări

Păstrarea progresului vechi, validarea importurilor și prevenirea recompenselor duplicate. Rezultatele întârziate sunt legate de cursa care le-a generat. Service worker-ul curăță doar cache-urile acestui joc.

Ce demonstrează

Logică de produs, simulare, generare procedurală, date locale versionate, design adaptabil și verificări de regresie.

Serverul pentru multiplayer, conturi, clasament comunitar și cloud este inclus, dar nu este găzduit public. Split-screen-ul local, obstacolele dinamice și editorul avansat sunt disponibile. Testele din browser nu înlocuiesc verificarea pe un telefon real. Fotografiile exportate folosesc randarea 2D.

Carpați Enduro

Motorcycle racing × enduro × trial · Expedition 2.1

Problem

A browser motorcycle game needs accessible controls and varied obstacles that reward learning. Small touch targets and continuous holds can exclude mobile players.

Solution

One experience for AI races, trial, staged expeditions and player-built courses. Touch controls can be enlarged, grouped, repositioned or toggled. Assist, game speed and sensitivity are adjustable.

Implementation

HTML, CSS and JavaScript, point-and-constraint physics, deterministic terrain, AI opponents and Three.js rendering with a Canvas 2D fallback. Tire pressure, suspension and brake balance affect simulation. Local rankings are separated by race rules.

UI and UX

The existing menu is retained. Expedition Studio brings together new modes, the editor, missions, tuning, local friends play, replays, analysis and backups. RO/EN, dark/light, high contrast and reduced motion are available.

Challenges

Preserving legacy progress, validating imports and preventing duplicate rewards. Delayed results are scoped to the race that created them. The service worker cleans up only this game's caches.

What it demonstrates

Product logic, simulation, procedural generation, versioned local data, adaptable design and regression checks.

The multiplayer/account/community-ranking/cloud server is included but not publicly hosted. Local split-screen, dynamic obstacles and the advanced editor are available. Browser checks do not replace testing on a physical phone. Exported photos use the 2D renderer.
