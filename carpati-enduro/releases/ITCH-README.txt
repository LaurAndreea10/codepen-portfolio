Carpați Enduro 2.1 — HTML package for itch.io

1. Open your itch.io dashboard and create/edit a project.
2. Choose an HTML/browser game and upload carpati-enduro-2.1.0-itch.zip.
3. Mark the ZIP as playable in the browser. Its root contains index.html.
4. Enable fullscreen and mobile-friendly embedding; test touch controls and the iframe on your own phone before publishing.

The game has RO/EN, local save/backup, 2D fallback, optional Three.js 3D and a PWA shell. Three.js/fonts need an initial network load. User browser/iframe storage rules can affect persistence; backup export is available.

The Node server is not inside this browser ZIP. Online rooms/accounts/cloud need the separate server in the source repository and an HTTPS address entered in the game's Online panel. The ZIP does not create a hosted backend or an itch.io listing automatically.

Keep the existing version history in the repository. This package is prepared for upload; no account upload has been performed.
