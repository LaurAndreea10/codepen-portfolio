# 📚 ExamSpace V–VIII

ExamSpace V–VIII is a browser-first, bilingual Romanian/English study space for grades 5–8. It follows the learning patterns used in BACapp and BAC Learning Space: dashboard, structured lessons, quick sheets, quizzes, planning, simulations, local progress and an accessibility centre.

## Included

- Dashboard with next mission, progress, streak and study time
- Subjects and lessons for mathematics, Romanian, science, history, geography and English
- Formula vault with search and voice readout
- Active-recall memory cards with spaced-review guidance
- Quiz mode with explanations and mistake review
- Seven-day study plan and focus timer
- Timed orientation simulation
- Official past-paper archive for National Assessment grade 8, with year filters and links to subjects + marking schemes
- Dark/light theme, high contrast, larger text, reduced motion, keyboard navigation and voice readout
- Romanian/English interface toggle
- Local export/import/reset of progress
- Lightweight offline cache and no backend

## Important note

ExamSpace is an orientation learning and organization tool. It is **not official teaching material**, does not replace a teacher, textbook, curriculum or classroom assessment, and does not guarantee an exam result.

No account, ads or server-side profile are required. Preferences and progress are stored locally in the browser.

The archive links to the official Ministry of Education pages. For grades 5–7, the app provides orientation practice and learning materials; it does not present them as an official national exam archive.

## Run

Open `dist/index.html` in a browser or serve the `dist/` directory from a static host.
