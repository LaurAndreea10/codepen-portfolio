How I work with AI

AI as a building and learning partner

I use Claude to build faster and to understand better what I am building. My rule: nothing goes public unverified.

01 · RULE

Define the problem

I start from what must stay at the centre, for example the official rule of a CodePen Challenge.

02 · BUILD

Implement with Claude

I work alongside AI and ask for explanations of the decisions I don't understand yet, so the lesson stays, not just the code.

03 · VERIFY

Test

Automated tests, Lighthouse and axe; where they exist, test results are public.

04 · NOTE

Write the limits

Whatever I have not verified yet, such as real phones or screen readers, I state explicitly in the README and the log.

  • AI-assisted drafts are labelled as such
  • Public code with version history
  • Anthropic certification: Claude Code in Action
