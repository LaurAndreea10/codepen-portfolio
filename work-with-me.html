Cum lucrez la un proiect

How I work on a project

  1. Clarific problemaClarify the problem

    Pornesc de la cine folosește produsul, ce vrea să facă și unde apare fricțiunea.

    I start from who uses the product, what they need to do and where the friction is.

  2. Plan scrisWritten plan

    Scope clar, livrabile și ce rămâne în afara versiunii. Fără cuvinte vagi.

    Clear scope, deliverables and what stays out of the version. No vague words.

  3. Iterații miciSmall iterations

    Versiuni numerotate, changelog public și teste automate unde se poate.

    Numbered versions, a public changelog and automated tests where possible.

  4. Publicare & documentarePublish & document

    Cod documentat, README clar, deploy pe GitHub Pages și limite notate onest.

    Documented code, clear README, GitHub Pages deploy and honestly stated limitations.
