ANIMAȚIE · 02

Stagger fără nth-child()

Întârzierea și înălțimea fiecărei bare sunt calculate din index.

calc(index × delay)
/* delay personalizat pentru fiecare frate */
.bar {
  --i: sibling-index();
  animation-delay: calc(var(--i) * 65ms);
  height: calc(24px + var(--i) * 13px);
}

ÎNVAȚĂ · 04

Mic laborator CSS

Parcurge exemplele, compară tehnicile și încearcă quiz-ul.

1. sibling-index()

Întoarce poziția curentului element printre frații cu același părinte: primul este 1, al doilea 2 și așa mai departe.

transform: rotate(calc(sibling-index() * 10deg));
2. sibling-count()

Întoarce numărul total de frați direcți. Util pentru a adapta un layout la conținutul real.

width: calc(100% / sibling-count());
3. Împreună, în calc()

Indexul stabilește poziția; numărul total împarte cercul în segmente egale.

rotate(calc((sibling-index() - 1) * 1turn / sibling-count()));

COMPARAȚIE · 05

nth-child() scris manual vs sibling-*

Ambele pot stiliza elemente după poziție. sibling-index() și sibling-count() pot exprima formule care se adaptează la numărul real de copii.

nth-child()

.item:nth-child(1) { --i: 1; }
.item:nth-child(2) { --i: 2; }
.item:nth-child(3) { --i: 3; }
/* reguli suplimentare pentru fiecare poziție */

sibling-index()

.item {
  --i: sibling-index();
  --n: sibling-count();
  rotate: calc(var(--i) * 1turn / var(--n));
}
✦
Fallback inclus — Acest demo include poziții nth-child() ca fallback pentru browserele fără suport sibling-*.
