ExamSpace V–VIII

Un workspace calm pentru pregătirea examenelor: înțelege lecția, fixează formulele, exersează, verifică baremul și revino la ce ai greșit.

A calm preparation workspace: understand lessons, retain formulas, practise, check marking schemes and revisit mistakes.

Deschide aplicația / Open app ↗Versiunea live ↗

Problemă / Problem

Pregătirea poate deveni fragmentată între formule, memorare, teste și verificarea baremului. Pentru V–VII este nevoie de structură și exercițiu; pentru VIII este utilă și arhiva examenelor precedente.

Preparation can become fragmented across formulas, memory work, tests and marking schemes. Grades 5–7 need structure and practice; grade 8 also benefits from past exam papers.

Soluție / Solution

Un produs cu dashboard, materii, lecții, seif de formule, memoratoare, quiz, plan pe 7 zile, simulare și arhivă oficială.

One product with dashboard, subjects, lessons, formula vault, memory cards, quiz, seven-day plan, simulation and official archive.

Decizii / Decisions

  • Local-first: fără cont, backend sau reclame; progresul se păstrează în browser.
  • Accesibilitate: RO/EN, skip link, tastatură, dark/light, contrast ridicat, text mărit, reduced motion și citire vocală.
  • Conținut: formule și memoratoare pentru V–VIII; linkuri către paginile oficiale cu subiecte și bareme pentru EN VIII.
  • Transparență: aplicația precizează că nu este material didactic oficial și nu garantează rezultatul la examen.

Rezultat / Result

ExamSpace V–VIII este o aplicație statică, responsive și bilingvă, pregătită pentru GitHub Pages și integrată ca proiect educațional finalizat în portofoliu.

ExamSpace V–VIII is a static, responsive bilingual app prepared for GitHub Pages and integrated as a finished educational project in the portfolio.

Notă: ExamSpace este un instrument de pregătire orientativă. Nu este material didactic oficial și nu înlocuiește profesorul, manualul, programa sau evaluarea de la clasă.
