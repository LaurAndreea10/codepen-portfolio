Case study · TOP 03 · Automation

Link Video Editor Studio

I turned preparing a video project into a repeatable workflow with presets, validation and reusable exports. A personal project, built in my free time.

Problem

Starting from scratch every time

Every video project needed the same planning steps, done by hand each time, with no shared structure for handoff.

Decision

Presets + workflow generator

Reusable presets, a generator that builds the timeline from a brief, and validation before export.

Result

Structured handoff

Structured JSON and HTML exports for handing off the video project, plus a documented Automation Pack.

Observable evidence

  • Stack: semantic HTML, CSS, JavaScript, GitHub Pages.
  • Architecture: presets, workflow generator, JSON/HTML export and Automation Pack.
  • Ownership: concept, UX, implementation and documentation — Laura Andreea.
  • Setup: no build step; open index.html or use a local static server.
Live demo Source code on GitHub Automation Pack: timeline and export

What I practised

Turning a repetitive process into a tool: structured data instead of manual steps, validation before export and a handoff format someone else can use.
