Traduceri maghiară și ucraineană cu DeepL

Pagina arată doar textele unde traducerea DeepL diferă de cea actuală din joc. Bifează „Păstrez varianta actuală” unde nu vrei schimbarea, apoi salvează lista pe GitHub și pornește aplicarea.

  1. În GitHub: Actions → Curious Garden DeepL translations → Run workflow, cu modul review. Raportul apare aici după 1–2 minute.
  2. Verifică aici și bifează ce păstrezi. Apasă „Copiază lista”, apoi „Salvează keep.json pe GitHub”.
  3. Pornește același workflow cu modul apply. Traducerile DeepL intră în joc, iar testele rulează automat înainte de publicare.
