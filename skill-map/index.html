Proiectele, după ce demonstreazăProjects, by what they prove

Tag-urile din catalog spun ce e un proiect („joc”, „CRM”). Aici le citesc invers: ce abilitate dovedește fiecare. Alege una sau mai multe; cu mai multe, rămân doar proiectele care le au pe toate.Catalogue tags say what a project is ("game", "CRM"). Here I read them the other way round: which skill each one proves. Pick one or more; with several, only projects that have all of them remain.

Potrivirea e automată: caut cuvinte-cheie în tag-urile și descrierea fiecărui proiect din projects.json, iar „Testare automată” vine din lista de suite de la pagina Teste. Poate rata un proiect descris prea scurt.Matching is automatic: I look for keywords in each project's tags and description in projects.json, and "Automated testing" comes from the suite list on the Tests page. It can miss a project with a very short description.
