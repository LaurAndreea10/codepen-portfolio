# CHRONOSCROLL × Baseline Voyage

Created 9 November 2026 by Laura Andreea, with AI assistance.

A bilingual CSS animation-timeline demo combining a 3D browser observatory, chronological browser milestones, scroll progress, named-timeline remote gauge, horizontal/cinema gallery and configurable CSS lab.

RO/EN, dark/light, seven palettes, contrast, reduced motion (system preference always wins), optional 3D and particles, four presentation modes, guide, exercises, local passport, local preferences and optional synthesized audio. No dependencies or external fonts.

Open index.html in a browser. Use the in-app export for a complete single HTML file. The downloads folder contains the CodePen package. Paste codepen.html, style.css and script.js into the corresponding CodePen panels, with no preprocessors.

Tags: cpc-animation-timeline, codepenchallenge. Dates are from the official CodePen starter. Support detection checks recognition, not browser rendering correctness. Registered-property/counter/gradient animations may repaint; animation-timeline does not guarantee compositing. The UI remains readable without JavaScript.

See CHANGELOG.md for validation and known verification limits.
