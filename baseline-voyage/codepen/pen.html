How is this animated?Cum e animat?

The section declares view-timeline: --journey. The glowing line (scaleY) and the giant year (an @property integer) both read it. Each card uses view() twice: one range to fly in, another (cover 25% cover 75%) to light up while it is the current event.Secțiunea declară view-timeline: --journey. Linia luminoasă (scaleY) și anul uriaș (un număr întreg @property) o citesc amândouă. Fiecare card folosește view() de două ori: un interval pentru intrare, altul (cover 25% cover 75%) ca să se aprindă cât timp e evenimentul curent.

    CSS glossaryGlosar CSS

    animation-timeline
    Swaps the clock of an animation: instead of seconds, progress comes from a scroll or view timeline.Schimbă ceasul animației: în loc de secunde, progresul vine dintr-o cronologie de scroll sau de vizibilitate.
    scroll()
    An anonymous timeline from a scroller's position (0% top, 100% bottom).O cronologie anonimă din poziția unui scroller (0% sus, 100% jos).
    view()
    An anonymous timeline from an element's visibility inside its scroller.O cronologie anonimă din vizibilitatea unui element în scrollerul său.
    animation-range
    Which part of the timeline the animation occupies, e.g. entry 0% cover 50%.Ce porțiune a cronologiei ocupă animația, de ex. entry 0% cover 50%.
    entry / exit
    The phases while the element enters or leaves the scrollport.Fazele în care elementul intră în zona vizibilă sau iese din ea.
    cover / contain
    cover: from first pixel in to last pixel out. contain: while fully inside (or fully covering).cover: de la primul pixel intrat la ultimul ieșit. contain: cât timp e complet înăuntru (sau acoperă complet).
    scroll-timeline
    Gives a scroller's timeline a name (--name) and an axis.Dă un nume (--name) și o axă cronologiei unui scroller.
    view-timeline
    Names an element's view timeline so others can use it.Denumește cronologia de vizibilitate a unui element, ca s-o folosească și alții.
    timeline-scope
    Makes a named timeline visible to a whole subtree, not just descendants of its owner.Face o cronologie denumită vizibilă unui subarbore întreg, nu doar descendenților proprietarului.
    @property
    Registers a typed custom property so numbers can be animated (the year, the percentages).Înregistrează o proprietate personalizată cu tip, ca numerele să poată fi animate (anul, procentele).

    Questions & answersÎntrebări și răspunsuri

    How does the fallback work?Cum funcționează fallbackul?

    Each feature is detected separately: scroll(), view(), animation-range, timeline-scope and registered properties. Without core support, requestAnimationFrame syncs the progress values and IntersectionObserver reveals the events. If only timeline-scope is missing, a script updates the badges, gauges and route map. You can simulate it from Settings or the Compatibility chapter.Fiecare funcție e detectată separat: scroll(), view(), animation-range, timeline-scope și proprietățile înregistrate. Fără suportul de bază, requestAnimationFrame sincronizează valorile de progres, iar IntersectionObserver dezvăluie evenimentele. Dacă lipsește doar timeline-scope, un script actualizează insignele, indicatoarele și harta traseului. Îl poți simula din Setări sau din capitolul Compatibilitate.

    What runs on the main thread?Ce rulează pe firul principal?

    In native mode, CSS drives every scroll effect, with no scroll listeners. transform and opacity can be composited efficiently; animated counters, gradients and clip-path may still need style recalculation or repaint. Using animation-timeline does not guarantee that every effect runs on the compositor.În modul nativ, CSS conduce fiecare efect de scroll, fără listeneri de scroll. transform și opacity pot fi compuse eficient; contoarele, gradienții și clip-path animate pot necesita totuși recalculare de stil sau redesenare. Folosirea animation-timeline nu garantează că fiecare efect rulează în compositor.

      How is the ship animated?Cum e animată nava?

      The transparent scroller in the arena declares scroll-timeline: --pilot block. The ship layer, a sibling, reads it through timeline-scope and animates a registered --py number from 0 to 1; the ship's translate is computed from it. The game loop only reads the same scroll progress to check collisions. Without native support, the script writes --py itself.Scrollerul transparent din arenă declară scroll-timeline: --pilot block. Stratul navei, un frate al lui, îl citește prin timeline-scope și animă un număr înregistrat --py de la 0 la 1; translate-ul navei se calculează din el. Bucla jocului doar citește același progres de scroll ca să verifice coliziunile. Fără suport nativ, scriptul scrie singur --py.
