## Description (EN)
A scroll-driven voyage through browser history, from Chrome 115 (2023) to Safari 26 (2025) and Firefox 159 (2026), when `animation-timeline` became Baseline.

Every scroll effect is CSS: `scroll()`, `view()`, `view(inline)`, `animation-range`, named `scroll-timeline` / `view-timeline`, `timeline-scope` and `@property`. It includes CHRONO PILOT, a game where the scrollbar is the joystick (the ship rides `animation-timeline: --pilot`), a 3D universe of engines, portal transitions between chapters, a horizontal gallery, remote-controlled followers, an interactive CSS lab with challenges, a glossary and a live compatibility check.

Created 9 November 2026. RO/EN · 7 palettes in dark/light · cinema gallery · reduced motion, no-3D, high contrast, text size and effect intensity · optional synthesized sound · `@supports` + IntersectionObserver fallback, plus a fallback simulator and a static mode.

Made by Laura Andreea, with AI assistance.
