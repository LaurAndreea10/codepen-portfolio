CHAPTER SHIFT / CSS VIEW()

The toolkit behind this PenUneltele din spatele acestui Pen

  • scroll()

    Ties an animation to a scroller's progress: the bar and ring up top.Leagă animația de progresul unui scroller: bara și inelul de sus.

    .progress-bar {
  animation: grow-x linear both;
  animation-timeline: scroll(root);
}

  • view()

    Tracks an element crossing the viewport: each event flies in.Urmărește un element care traversează viewport-ul: fiecare eveniment intră în scenă.

    .event {
  animation: arrive linear both;
  animation-timeline: view();
}

  • animation-range

    Picks which slice of the timeline plays: the title shrinks only while exiting.Alege ce porțiune a cronologiei rulează: titlul se micșorează doar când iese.

    .hero__title {
  animation-timeline: view();
  animation-range: exit 0% exit 90%;
}

  • view-timeline

    Names a timeline so children can reuse it: the line and the giant year.Denumește o cronologie ca s-o refolosească alții: linia și anul uriaș.

    .journey { view-timeline: --journey; }
.year { animation-timeline: --journey; }

  • timeline-scope

    Lifts a name up the tree: the header badges light up from far away.Ridică un nume în arbore: insignele din header se aprind de la distanță.

    body { timeline-scope: --e1, --e2, --e3; }
.badge:nth-child(1) {
  animation-timeline: --e1;
}

  • @supports

    Older browser? A small IntersectionObserver fallback keeps it all working.Browser mai vechi? Un fallback mic cu IntersectionObserver păstrează totul funcțional.

    @supports not (animation-timeline: scroll()) {
  /* JS sets --scroll instead */
}

Cum funcționează fallbackul?How does the fallback work?

Detectăm separat scroll(), view(), animation-range, timeline-scope și proprietățile înregistrate. Dacă lipsește suportul de bază, requestAnimationFrame sincronizează progresul și IntersectionObserver dezvăluie evenimentele. Dacă lipsește doar scope, JavaScript actualizează cadranele și insignele. Poți simula fallbackul din Setări.We separately detect scroll(), view(), animation-range, timeline-scope and registered properties. If core support is missing, requestAnimationFrame synchronizes progress and IntersectionObserver reveals events. If only scope is missing, JavaScript updates gauges and badges. You can simulate fallback mode in Settings.

Ce rulează pe firul principal?What runs on the main thread?

CSS conduce animațiile în modul nativ. Transform și opacity sunt alegeri eficiente; contoarele și gradienții animați pot necesita recalculare sau redesenare. Folosirea animation-timeline nu garantează executarea tuturor efectelor în compositor.CSS drives animations in native mode. Transform and opacity are efficient choices; animated counters and gradients may need recalculation or repainting. Using animation-timeline does not guarantee that every effect runs in the compositor.
