Validation: JavaScript syntax, HTML structure and internal-link checks; Chrome UI checks for language, native/fallback mode, lab axes, gauge progress, reduced motion, settings, guide and persisted stamps. Safari, Firefox, physical mobile devices and screen readers are not independently verified.
