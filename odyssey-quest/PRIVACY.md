# Confidențialitate / Privacy

Actualizat / Updated: 2026-10-01 · v2.1.1

**RO** — Jocul nu solicită conturi și nu include servicii de analiză, publicitate sau colectare online. Browserul păstrează local progresul, preferințele, numele introduse, întrebările atelierului, scorurile și părerile. Nu introduce date sensibile. Opiniile salvate local nu ajung la autor; feedbackul ajunge la autor numai dacă alegi să trimiți un issue GitHub. Exporturile JSON pot conține datele profilurilor; distribuie-le numai dacă dorești. Ștergerea datelor site-ului din browser elimină toate profilurile, atelierul și părerile; resetarea din joc elimină numai profilul curent. Instalarea offline stochează fișierele jocului în cache. Hostingul primește solicitările obișnuite necesare livrării paginii și poate avea propriile jurnale și politici.

**EN** — The game needs no account and includes no analytics, advertising or online collection services. Your browser stores progress, preferences, entered names, workshop questions, scores and opinions locally. Do not enter sensitive data. Locally saved opinions are not delivered to the author; feedback reaches the author only if you choose to submit a GitHub issue. JSON exports may contain profile data; share them only if desired. Clearing browser site data removes all profiles, workshop questions and opinions; in-game reset clears only the active profile. Offline installation caches game files. The host receives ordinary requests needed to serve the page and may have its own logs and policies.

Features such as a private feedback inbox, cloud backups and public leaderboards would require a separately configured service and an updated privacy notice before activation.

## Mod conectat / Connected mode

**RO** — Duelul WebRTC opțional folosește STUN Cloudflare pentru descoperirea rețelei și expune metadate de conexiune și adrese IP partenerului și serviciului STUN. Nu există server TURN sau server propriu care să stocheze progresul. „Trimite backupul” partajează cele trei profiluri locale, preferințele și părerile locale cu dispozitivul conectat; acceptarea înlocuiește starea jocului pe dispozitivul care primește. Alegerile narative rămân locale. Schimbă codurile de conectare doar printr-un canal privat, cu o persoană de încredere. Feedbackul GitHub devine public după ce îl trimiți; se aplică termenii GitHub. Nu se folosește e-mail.

**EN** — Optional WebRTC uses Cloudflare STUN for network discovery and exposes connection metadata/IP addresses to peers and the STUN service. No TURN relay or app server stores progress. Send backup shares all three local profiles, preferences and their local opinions with the connected peer; accept replaces the receiving device’s local game state. Narrative choices stay local and are not included in that backup. Exchange signaling codes privately and connect only to a trusted person. GitHub feedback is public after the player submits it; GitHub account and privacy terms apply. No email delivery is used.
