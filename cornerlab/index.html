Ce experimentez?

Proprietatea CSS experimentală corner-shape schimbă profilul colțurilor unui element cu border-radius. În funcție de browser, poate fi necesară o versiune experimentală sau activarea unei funcții din setări.

corner-shape: scoop;

Fallback inclus

Forma de bază rămâne definită prin border-radius. Regula nouă este izolată într-un @supports, așa că browserele care nu o cunosc afișează o versiune simplă și curată.

@supports (corner-shape: scoop) { … }
