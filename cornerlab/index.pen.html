01 · Spectrul superellipse

      
Toate formele sunt aceeași curbă

      
Fiecare cuvânt-cheie e un punct pe aceeași scală: superellipse(K). Mută sliderul de la −∞ (notch) la +∞ (square) și urmărește cum se transformă colțul. Previzualizarea e SVG, deci arată corect în orice browser.

04 · Muzeul CSS experimental

      
Alte experimente CSS

      
Fiecare mostră încearcă o funcție sau un selector experimental. Indicatorul se actualizează după capabilitățile browserului.

      

        
CSS if()—
Valoarea stilului răspunde unei condiții style query.
if(style(…)) → color

        
CSS @function—
Funcție reutilizabilă pentru tokenuri de design.
--lab-space(1)

        
text-overflow—
Text personalizat la marginea unui titlu tăiat.
Sibylline synthesis of experimental corner geometries…

        
reversed()—
Contor CSS invers pentru pași numărați în jos.
  1. Testează
  2. Ajustează
  3. Publică

        
Counter scope—
Demonstrație de resetare locală a contorului.
counter-reset: item 0;
counter-increment: item;

        
color-mix() × 3—
Amestecă trei culori pentru o mostră de paletă.

        
CSS Grid Lanes—
Mosaic cu fallback grid și layout experimental pe coloane.

        
:heading—
Stilizează titlul găsit de pseudo-clasa.
Titlu detectat

::field-content—
Stilizează conținutul unui input cu pseudo-elementul.

      

    


    

      
Ce experimentez?
Proprietatea CSS experimentală corner-shape schimbă profilul colțurilor unui element cu border-radius. Bordura, umbra și fundalul urmează forma nouă. În funcție de browser, poate fi necesară o versiune experimentală sau activarea unei funcții din setări.
corner-shape: scoop;

      
Fallback inclus
Forma de bază rămâne definită prin border-radius, iar regula nouă e izolată în @supports. Unde lipsește suportul nativ, un script mic calculează aceeași curbă superellipse și o aplică prin clip-path: path(), cu un contur SVG în locul bordurii.
@supports (corner-shape: scoop) { … }
