# VOID HUNTER · CSS random() Edition

## RO

Copie a jocului [VOID HUNTER](https://laurandreea10.github.io/VOID-HUNTER-Space-Shooter/), pen-ul meu cu cele mai multe aprecieri, la care am adăugat un oracol CSS `random()`. Originalul rămâne neschimbat.

- Același joc: LANSARE, EASY/NORMAL/HARD, auto-fire, turbo, joystick pe mobil, vibrații, boss cu nuclee, AI care ajustează dificultatea.
- Nou: înainte de fiecare val, un card de oracol alege cu CSS `random()` modificatorul valului (`random(0, 7, 1)`), trei zaruri pentru bonus (`random(1, 6, 1)`) și culoarea navei (`random(0, 359, 1)`). JavaScript doar citește valorile calculate.
- Opt modificatori: puncte duble, roi rapid, scut cadou, foc rapid, vid fragil, fântână gravitațională, multiplicator +2, viață în plus. Trei zaruri egale = o viață.
- Stele și meteori în plus, poziționați de `random()`; fallback JavaScript în browserele fără suport.

## EN

A copy of [VOID HUNTER](https://laurandreea10.github.io/VOID-HUNTER-Space-Shooter/), my most-liked pen, with a CSS `random()` oracle added. The original stays unchanged.

- Same game: LAUNCH, EASY/NORMAL/HARD, auto-fire, turbo, mobile joystick, vibration, core-based boss, AI difficulty scaling.
- New: before every wave, an oracle card uses CSS `random()` to pick the wave modifier (`random(0, 7, 1)`), three bonus dice (`random(1, 6, 1)`) and the ship colour (`random(0, 359, 1)`). JavaScript only reads the computed values.
- Eight modifiers: double points, fast swarm, gift shield, rapid fire, fragile void, gravity well, multiplier +2, extra life. Three matching dice = a life.
- Extra stars and meteors placed by `random()`; JavaScript fallback where it is not supported.
