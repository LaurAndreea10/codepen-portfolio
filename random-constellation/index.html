Cum funcționează CSS random()?

CSS alege poziții, dimensiuni, nuanțe și viteze în limitele declarate. JavaScript creează numărul de elemente și interfața; nu calculează valorile aleatoare pentru stele.

.star {
  left: random(3%, 97%);
  top: random(5%, 95%);
  --size: random(2px, 5px, 1px);
  --depth: random(-110px, 95px);
}
.oracle {
  --pick: random(0, 11, 1);
  --d1: random(1, 6, 1);
}
.linked .oracle {
  --d1: random(--dice, 1, 6, 1);
}

Butonul de regenerare creează elemente noi, iar CSS le atribuie alte valori random().

Oracolul: prezicerea e o bandă de 12 rânduri mutată cu --pick, iar totalul zarurilor e un counter CSS. Cheia comună --dice face ca toate zarurile să primească aceeași valoare. Fără suport random(), doar oracolul și efectele primesc valori din JavaScript; stelele păstrează fallback-ul static.

Accesibilitate și compatibilitate
  • Toate comenzile au etichete și se folosesc din tastatură.
  • Contrast ridicat și mișcare redusă pot fi activate manual.
  • Setarea de mișcare redusă a sistemului este respectată.
  • Dacă browserul nu recunoaște random(), scena păstrează o distribuție statică utilizabilă.
  • Exportul și partajarea nu trimit date către un server.
