# VOID ORACLE — CSS random() Space Shooter

## RO

Shooter spațial inspirat de [VOID HUNTER](https://github.com/LaurAndreea10/VOID-HUNTER-Space-Shooter), făcut pentru CodePen Challenge CSS Random() din noiembrie 2026.

- Înainte de fiecare val, un card de oracol alege cu CSS `random()` modificatorul valului (`random(0, 7, 1)`), trei zaruri pentru bonus (`random(1, 6, 1)`) și culoarea navei (`random(0, 359, 1)`). JavaScript doar citește valorile calculate și le aplică în joc.
- Opt modificatori: ploaie de meteoriți, puncte duble, roi rapid, scut cadou, foc rapid, vid fragil, fântână gravitațională, Nova încărcată. Trei zaruri egale dau o viață în plus.
- Trei tipuri de inamici, boss cu trei faze la fiecare al cincilea val, power-up-uri (scut, foc triplu, foc rapid, viață), combo până la ×5 și bomba Nova.
- Cerul din spate (stele, nebuloase, meteori) e poziționat tot de `random()`.
- Tastatură, mouse și atingere; RO/EN; sunet și mișcare redusă comutabile; pauză automată când pleci din tab; anunțuri pentru cititoare de ecran; record salvat local.
- Fără suport `random()`, JavaScript completează aceleași proprietăți custom.

## EN

A space shooter inspired by [VOID HUNTER](https://github.com/LaurAndreea10/VOID-HUNTER-Space-Shooter), made for the November 2026 CodePen CSS Random() Challenge.

- Before every wave, an oracle card uses CSS `random()` to pick the wave modifier (`random(0, 7, 1)`), three bonus dice (`random(1, 6, 1)`) and the ship colour (`random(0, 359, 1)`). JavaScript only reads the computed values and applies them.
- Eight modifiers: meteor shower, double points, fast swarm, gift shield, rapid fire, fragile void, gravity well, Nova charged. Three matching dice give an extra life.
- Three enemy types, a three-phase boss every fifth wave, power-ups (shield, triple shot, rapid fire, life), combo up to ×5 and the Nova bomb.
- The background sky (stars, nebulae, meteors) is placed by `random()` too.
- Keyboard, mouse and touch; RO/EN; sound and reduced-motion toggles; auto-pause when leaving the tab; screen-reader announcements; best score saved locally.
- Without `random()` support, JavaScript fills in the same custom properties.
