# Changelog

## 2.0.0 · 22 October 2026 · Night Fair Studio

- Five workspaces: Scale, Studio, Play, Collection, Settings. Romanian and English; category names stay unchanged for the challenge.
- Pound state is preserved across lb/kg/g switches; six precise presets, random weights, reset, nonlinear dial and slider, over-range indicator and next-threshold distance.
- SVG pumpkin shapes, automatic category expressions and oni horns, explicit face templates, custom colors, hats and unlockable accessories. Lantern illumination, leaf, stem, fair decorations, weather and seasons.
- Paint, carve, erase, touch drawing, keyboard-accessible templates/patterns/stickers, undo/redo, 60-design gallery, favorites, duplicate, reopen and delete recovery.
- Nine modes: weight estimate, category, precision watering, boundaries, time attack, simulated AI championship, local two-player, deterministic daily challenge with catch-up, resource-based growth. Pause, adjustable timer, XP, levels, badges, quests and local leaderboard.
- Up to 1000 named weigh-ins, filtering, sorting, comparison, mean/median/max, category histogram, record progression. JSON backup/import with schema validation, CSV export, PNG certificate, SVG export, print and shareable basic designs.
- Synthesized optional sounds/ambience, volume, dark/light, high contrast, reduced motion, paused scenery, larger text, low effects, display choice and configurable long presses.
- Offline app shell, install manifest, scoped service worker and user-controlled updates. No accounts, remote AI, analytics or paid services.
- Growth regression: twelve available actions allow the 100 lb target to be reached; winning precision/growth paths are tested. Canonical weight restores consistently with lb/kg/g preferences.
- Automated verification: Node logic tests; browser flows for all modes, persistence/import, export, keyboard, small screens, timing and offline; axe scans of all five panels.
