Cum sunt construite

Fără backend

Totul rulează pe GitHub Pages. ZIP-urile sunt asamblate în browser de un writer scurt, fără biblioteci, PDF-urile vin din fereastra de printare, PNG-urile din canvas.

Web Components

Widgeturile și kitul de dashboard sunt custom elements cu Shadow DOM, deci pot fi lipite pe orice site fără conflicte de CSS.

Accesibile din start

RO/EN, dark/light, contrast ridicat, folosire din tastatură, regiuni live pentru rezultate și respect pentru mișcarea redusă — pe fiecare pagină.

Întrebări

Sunt chiar gratuite?

Da. Codul are licență MIT; șabloanele și fișele sunt gratuite pentru uz personal, la clasă și comercial. O mențiune e apreciată, nu obligatorie.

Ce scriu e trimis undeva?

Nu. Paginile nu au server și nici tracking; fișierele sunt construite pe dispozitivul tău. Doar alegerea temei și a limbii e ținută minte în browser.

De ce produse, nu doar proiecte?

Pentru că un produs trebuie să poată fi folosit de altcineva: instalare clară, descărcare, documentație și cazuri-limită. E cel mai bun exercițiu pe care îl știu ca să cresc ca developer.
