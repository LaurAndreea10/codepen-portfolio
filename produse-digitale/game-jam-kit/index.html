Game Jam Kit

Părțile pe care le rescriu în fiecare joc de browser, adunate într-un singur fișier mic: loop cu pas fix care se oprește odată cu tabul, input din tastatură/touch/pointer, RO/EN, salvări versionate, sunete generate și ajutoare de accesibilitate. Mai jos e un mic joc construit doar cu kitul.

API

createLoop({ update, render, fps })
Pas fix, recuperare limitată, se oprește când tabul e ascuns.
createInput(map)
Acțiuni mapate pe taste; isDown, wasPressed, bindPointer(canvas), bindButtons().
createI18n(dict, key)
t('cheie', {vars}), apply() pe data-i18n și data-i18n-label, set('en').
createSave(name, version, defaults)
localStorage versionat: o versiune nouă resetează în siguranță salvările vechi.
createAudio()
Sunete Web Audio fără fișiere: tone(), coin(), hit(), win(), muted.
a11y.reducedMotion · a11y.announce(msg)
Respectă prefers-reduced-motion; anunță scorul și evenimentele cititoarelor de ecran.
createHud({ score: '#score' })
Actualizează DOM-ul doar când se schimbă valoarea.
util.fitCanvas · clamp · rand · hit
Canvas clar pe ecrane retina, coliziuni între cercuri, utilitare.
const loop = GameKit.createLoop({
  update(dt) { player.x += input.isDown("right") ? speed * dt : 0; input.endFrame(); },
  render() { ctx.clearRect(0, 0, W, H); drawPlayer(); }
});
loop.start();
