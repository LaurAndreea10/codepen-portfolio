## Reguli

- Maximum 5–7 topics relevante per repository.
- Versiunile canonice primesc topic-ul `portfolio-project`.
- Variantele istorice primesc `historical-version`.
- Topics descriu funcția proiectului, nu adjective precum „amazing” sau „premium”.

Notă: documentul stabilește standardul. Topics din interfața GitHub necesită permisiunea de administrare a metadatelor repository-ului.
